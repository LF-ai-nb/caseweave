# 技术决策记录

## ADR-001：选择确定性贪心覆盖

状态：已采纳

背景：组合测试矩阵需要在覆盖率和用例数量之间折中。最优 covering array 求解成本高，也会引入较复杂的求解器依赖。

决策：使用确定性候选枚举加贪心选择。每轮选择覆盖新增交互最多的候选行，平局时保留枚举顺序。

影响：生成结果可复现，易于调试和审计。输出不保证全局最小，但适合工程测试计划。

## ADR-002：约束 DSL 保持轻量

状态：已采纳

背景：项目需要表达常见配置限制，例如 Safari 只支持 macOS、某些区域不支持某种登录方式。

决策：实现布尔表达式 DSL，不引入外部解析器或求解器。

影响：库可以跨 wasm、JS、native 使用；复杂数值约束暂不支持。

## ADR-003：核心库不做文件 IO

状态：已采纳

背景：不同运行目标对文件系统支持不同，库如果直接做 IO 会降低可移植性。

决策：核心导出函数返回字符串，由调用方决定写文件、打印或上传。

影响：库更小、更稳定，也更适合被 CI 和其他工具嵌入。
