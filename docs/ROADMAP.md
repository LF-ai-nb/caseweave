# 路线图

## 0.1.x

- 保持无第三方运行时依赖。
- 完善导出格式，补充 HTML 或 JUnit 风格报告。
- 为约束错误增加更友好的位置提示。
- 增加更多真实场景示例。

## 0.2.x

- 增加从 JSON/YAML 读取模型的独立 CLI。
- 支持固定种子下的随机 tie-break 作为可选模式。
- 输出缺失交互的最小补充建议。

## 暂不计划

- 内置浏览器或设备执行器。
- 远程服务调用。
- Mooncakes 包审查、README/许可证审查、来源证明或报名材料审核。
- 依赖重量级约束求解器。
- 追求数学最优的最小覆盖数组。

CaseWeave 更适合保持小而稳定，作为测试计划生成和覆盖验证的基础库。
